# Структура каталогов и файлов
## ./main.py
- Файл запуска проекта.

## ./.env
- Файл, содержащий приватный токен Discord-бота. Не включается в публичную версию проекта.

## ./src/
- Каталог основного кода проекта, непосредственно связанного с его предметной областью.

## ./lib/
- Каталог самостоятельно разработанных модулей, не привязанных к контексту конкретного проекта.

### ./lib/check.py
- Декоратор проверки id.

### ./lib/unifer.py
- Декоратор для обьединения двух видов контекста: discord.etx.commands.Context и discord.Interaction.

### ./lib/time.py
- Надстройка над встроенной библиотекой datetime.

### ./lib/data_tools/
- Набор инструментов для конвертации данных между текстом, коллекцией и обьектом.

### ./lib/render_tools/
- Набор инструментов, что являются надстройкой над Discord обьектами и функциями, связанными с сообщением.

### ./lib/library/
- Набор данных, структурированный по тематике.

## ./data/
- Каталог централизованного хранения файлов данных.

### ./data/manager/
- Каталог инструментов управления `./data/` и инфрпмационными файлами в нём.

### ./data/default_data/
- Каталог для создания минимальной структуры `./data/`

## ./README/
- Каталог с документацией по проекту на различных языках.
