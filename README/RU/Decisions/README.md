# Назначение /Decisions/
В данной папке хранятся файлы с описанием принятых решений в формате ADR (Architecture Decision Records).

# Шаблон заполнения /Decisions/
Имя файла: ADR-{number}.md
```
# Decision name

**Статус**  
{Принято / На рассмотрении / Отклонено}

**Контекст**  
{Описание задачи, которое нужно решить}

**Варианты**  
- {Альтернативные способы решения}

**Последствия**  
Преимущества:  
- {Описание преимуществ данного конкретного решения}

Недостатки:  
- {Описание недостатков данного конкретного решения}

**Причина принятия решения**  
{Описание причины, по которой решение было принято или отклонено}
```

## Пример:
ADR-000.md
# Использование SQLite

**Статус**  
Принято

**Контекст**  
В проекте возникла необходимость долгосрочно хранить информацию пользователей.

**Варианты**  
- Json

**Последствия**  
Преимущества:  
- Экономия памяти

Недостатки:  
- Невозможность проверить содержимое .db файла

**Причина принятия решения**  
Решения удовлетворяет потребностям проекта.
